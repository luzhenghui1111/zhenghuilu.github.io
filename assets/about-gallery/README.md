# About Me photo gallery

Upload or delete image files in this folder to control the About Me carousel on the homepage.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.

Use numeric prefixes to control the order, for example:

- `01-ubc-campus.jpg`
- `02-conference.jpg`
- `03-outdoors.webp`

The homepage reads this folder automatically through the public GitHub Contents API. You do not need to edit HTML or JavaScript after adding or deleting photos.
